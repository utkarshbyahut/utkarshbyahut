# Utkarsh Byahut

**Graduate Researcher in Robotics and Autonomous Systems (AI) — Arizona State University**

I work on multi-agent coordination, edge perception, and getting autonomy off the simulator and
onto real hardware. Most of what I build sits at the point where a perception stack has to make a
decision with incomplete information and a power budget.

---

## Current research and engineering

**Autonomous aerial swarms** — Decentralized task allocation for homogeneous and heterogeneous
drone swarms operating in information-constrained environments, on motion-capture and PX4-based
flight stacks.

**Edge perception and deployment** — Custom object detection pipeline with low-level architecture optimization for real-time inference on NVIDIA Jetson.

**Manipulation and simulation** — Vision-Language-Action workflows and autonomous task simulation
in MuJoCo and NVIDIA Isaac Sim.
